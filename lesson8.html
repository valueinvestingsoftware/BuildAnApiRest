Lecture 8: API REST Project Creation

REST API Development: Build, Test, Troubleshoot

After understanding the fundamentals of REST APIs and configuring the development environment, the next step is to create the REST API project itself. This project will contain the structure, controllers, models, and configuration necessary to expose API endpoints that clients can use.

Creating the API Project

In many development environments, such as Visual Studio, creating a REST API project starts by selecting a web API template. This template generates the basic structure required for the application to run as a web service.

The generated project usually includes folders and files for:

  • Controllers that handle incoming HTTP requests
  • Models that represent application data
  • Configuration files for routing and services
  • Program startup configuration

Typical Project Structure

A typical REST API project structure might look like this:

/Controllers /Models /Services Program.cs appsettings.json

Each part of the structure serves a specific purpose in the architecture of the REST API.

Controllers

Controllers are responsible for receiving HTTP requests and returning responses. They define the endpoints that clients interact with.

Example endpoint inside a controller:

GET https://localhost:5001/api/products

This endpoint might return a list of products from the database.

Models

Models represent the structure of the data used by the application. For example, a product model might include properties such as ID, name, and price.

public class Product { public int Id { get; set; } public string Name { get; set; } public decimal Price { get; set; } }

Configuration Files

Configuration files store settings that control how the API runs. This can include database connections, logging configuration, and environment-specific settings.

Example database connection configuration:

"ConnectionStrings": { "DefaultConnection": "Server=localhost;Database=StoreDB;Trusted_Connection=True;" }

Testing the Initial API

Once the project is created, the API can be run locally. Testing tools such as Postman can send HTTP requests to verify that the API is working correctly.

Example request:

GET https://localhost:5001/api/products

If everything is configured properly, the server will return a JSON response containing product data.

Next Steps

Now that the REST API project has been created, the next step is to define the internal components of the API, including models and additional controllers that will manage application data.
